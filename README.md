# 晓檬朋友圈写作 Skill

把真实经历、做事过程和读书感悟，写成自然、口语化、可直接发布的朋友圈文案。

这个个人写作 Skill 以本人亲自修改的文案为参考。面向熟人，讲清楚做了什么、能帮到什么人、接着想怎么做。适用于 AI 实操、编程经验、知识库、自媒体成长、开公司与轻量社群邀请。

## 使用

安装：

```bash
npx skills add zhangxiaomeng1/xmeng-wechat-moments-skill -g
```

也可以将本仓库中的 `SKILL.md`、`references/` 和 `agents/` 放入技能目录 `xmeng-wechat-moments/`。具体支持情况取决于所用客户端。

在聊天里输入，例如：

```text
$xmeng-wechat-moments
把下面这段做事感悟改成朋友圈文案，真诚记录，只给完整成稿：……
```

```text
用晓檬朋友圈写作 Skill，把这条视频与我做知识库的经历连起来。
结尾只留感悟，不要提问或邀请私信。
```

```text
用晓檬朋友圈写作 Skill，写一条想建AI交流群的邀请。
群还没有建立，不要编造活动、人数或收费规则。
```

## 写作取向

- 从真实的小事出发，把实际过程和发现讲清楚。
- 分享者自己的理解与经历在前，外部观点用作补充。
- 阳明心学作为个人做事方式的思想参考，不用作收益或技术效果的证明，也不每篇套术语。
- 不扮演其他博主，不编造个人经历，不承诺流量、提效或收入。
- 结尾随目的变化；不是每篇都问“你用AI卡在哪里”。
- 用户只要最终文案时，一次交付完整稿件，不要求手动拼接。

## 文件与来源

- `SKILL.md`：写作流程与边界。
- `references/voice-and-values.md`：本人确认的文案样本、写作偏好和思想背景说明。
- `agents/openai.yaml`：技能显示信息。

参考样本由本人提供。创建过程另参考了本人的读书记录；这些记录含书摘和既有整理，未随本仓库公开，也不作为历史引文或现实结果的独立证明。

这是个人风格写作工具，不是姜胡说、王阳明或任何其他人物的官方产品。没有复刻他人的声音、身份或作品库，不依赖姜胡说口播 Skill。

当前已检查技能结构、引用文件和公开文件清单；尚未完成多模型或真实发布效果评测，不把结构检查通过当成文案质量或传播效果保证。
